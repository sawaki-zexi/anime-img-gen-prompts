## 1 看图到 Agent 取用的完整样例

**交付行为**

使用一条有真实来源的模板，跑通从内容录入、构建、网页详情与变量复制，到 MCP 搜索、读取和渲染的完整流程。作为后续内容扩充与插件接入的可运行基础。

**阻塞任务**

无，可首先实施。

**验收条件**

- 从一条独立的 Markdown 与元信息记录构建可供网页和 MCP 共用的版本化数据。
- 用户在首页打开条目，看到对应图片、实际提示词、适用信息和来源，填写变量后可复制。
- 通过真实 MCP 客户端调用搜索、详情与渲染，取得相同条目和修订，变量替换遵循共享规则。
- 缺少必填项、未知变量、错误 ID 和修订冲突均得到明确结果，草稿不进入公开内容。
- 具备可复现的本地启动、构建和自动检查入口，CI 验证本任务交付的完整流程。

**对应规格**

实现 AC01、AC03、AC08、AC09、AC10、AC12 的基础路径，后续任务补全各自范围内的验收。

## 2 多用途内容发现与二次元画廊

**交付行为**

让用户和 Agent 都能按用途、画风与适用模型找到可用内容。使用同一套规则驱动画廊与 MCP，提供六个真实对应的首发样例，覆盖人物创作及场景或壁纸等用途。

**阻塞任务**

任务 1。

**验收条件**

- 画廊实现已选主视觉、组件风格、分类、搜索、画风与模型筛选、详情、填写与复制，并适配手机与键盘。
- 用途与别名由内容词表驱动，新增用途能同时出现在网页与检索结果中。
- 六个已发布条目覆盖至少四种用途，包含人物及场景或壁纸，每条具有实际对应图片、生成依据和来源记录。
- 关键词、别名、筛选组合、排序与游标分页在网页和 MCP 中保持一致。
- 分享链接恢复查询条件，缩略图与大图按需加载，无结果和归档状态有明确表现。
- 自动化覆盖多用途检索、模板错误、图片及引用校验、手机交互与相同版本内容一致性。

**对应规格**

完成 AC01、AC02、AC03、AC04、AC09、AC10、AC12、AC13 的画廊与内容范围。

## 3 安装插件后跨项目使用

**交付行为**

把任务 Skill 和远程 MCP 连接打包成可安装插件。用户在其他项目描述头像、立绘、场景、壁纸、漫画、贴纸或表情包需求时，Agent 能识别适用任务、查找真实条目并整理提示词。

**阻塞任务**

任务 1。此任务不依赖六个正式样例全部完成，可先以任务 1 的真实条目验证安装与工具流程。

**验收条件**

- 插件包包含有效元信息、Skill 和可配置的远程 MCP 连接，普通用户流程使用托管服务。
- 安装说明与画廊接入入口指向可验证的分发方式，标注客户端的真实支持状态。
- 在两个不相关项目的新会话中验证用户级能力发现，不需要每个项目重复复制内容或配置。
- 正反向请求覆盖多种创作用途，记录自动匹配、真实 ID 使用、变量处理和不适用任务的结果。
- 有生图工具时完成提示词交接，没有时交付可直接使用的提示词，服务失败时提供明确回退。
- 插件包与工具契约有可复现的验证步骤，测试环境使用独立配置，保护用户现有安装。

**对应规格**

完成 AC05、AC06、AC07、AC08、AC15 中的插件和跨项目行为。

## 4 公开发布与更新验收

**交付行为**

让首次访问者可以打开公开画廊、安装插件并连接远程服务。维护者发布新内容后，现有用户可以直接检索到新增条目，并能定位版本和回退失败发布。

**阻塞任务**

任务 2 和任务 3。

**验收条件**

- 静态站点、插件分发产物和远程服务使用同一内容快照，提供可验证的生产入口与版本信息。
- 配置健康检查、请求与频率限制、失败响应、隐私友好的日志，以及可操作的回退步骤。
- 发布新增内容后，现有插件安装可以检索到新条目，无需重新安装。
- 一千条合成数据和受控并发运行验证规模目标，记录实际机器、耗时和资源请求情况。
- 在已标记支持的客户端完成干净环境安装与跨项目评测，按真实结果记录生图工具交接和第三方目录状态。
- 实际部署时使用届时确定的域名、托管账户及预算配置，将平台权限或目录审核所需输入明确记录。

**对应规格**

完成 AC09、AC10、AC11、AC14、AC15 的运行与发布范围，并汇总 AC01 至 AC15 的实际证据。

## 推进顺序与确认点

实施顺序建议为任务 1、任务 2、任务 3、任务 4。依赖关系为任务 1 支撑任务 2 与任务 3，任务 4 依赖任务 2 与任务 3。

具体前端构建器、服务运行配置和验证命令在实现中按 TypeScript、静态预渲染、daisyUI、Motion 及官方 MCP SDK 的既定方向确定。任务拆分确认后，按项目流程创建工单与隔离工作区，逐项提交可验收结果。PR 合并使用最终 PR 与验证结果单独确认。
